**我每天洗头梳头掉头发，我是“脱发”了吗？**
//头发是一种长圆柱状角质结构，深入皮肤内的部分称为毛根，毛根末端膨大呈葱头状，称为毛球，露出皮面的部分称为毛干。

毛囊位于真皮和皮下组织中，是毛发生长所必须的结构，也是人体的微小器官。一个人一生中只发生一次毛囊的形成，也就是说，一般情况下，我们头发的毛囊数量出生时就固定了。

我们的头发是周期性生长的，每根头发的“一生”可分为3个时期，**生长期、退行期和休止期**。

**生长活跃的“生长期”**：这个时期，头发每个月能长1cm左右，大概可持续3-4年左右（生长期决定头发长度），浓密的头发主要来自生长期的头发；

**慢慢退化的“退行期”**：生长期结束后，头发进入退行期，毛囊开始萎缩，头发停止生长，大约2-3周；

**修生养性的“休止期”**：退行期后，新的毛囊周期还没开始，这一段“默默无闻”的时期，就是休止期了。头发一般在这个时期自行脱落（梳头发、洗头发会掉的头发），大约持续3-4月。

不同时期的头发毛囊在皮肤的分布位置不同。生长期毛囊处于皮下组织，退行期毛囊处于真皮和皮下组织交界处，休止期毛囊处于真皮。

**正常人每天可脱落70-100根头发**，头发的生长和脱落是交替进行并保持平衡，所以看不出头发减少的现象。

一般每年三月份头发生长达高峰，九月份最低，此时每日脱发量也会增加（**脱发量增加会有季节性**）。随着年龄增加，毛囊也会逐渐减少；也就是说，**生理状态下，我们的发量随着年龄增加也会逐渐减少。所以呢，年龄大了，发量自然会减少；也就是说，头发少了，也是人衰老的一个标志。**

成年人的头皮面积约为500平方厘米，共有大概10至15万根头发。其中约90%处于生长期，1%处于退行期，10%处于休止期。如果平均每天掉的头发超过100根，并持续较长时间（1-2个月），肉眼可以觉察到头发稀疏，就需要**及时找专业的毛发医生**，查明原因。

**常见的脱发性疾病有哪些呢？**
//**雄激素性脱发**
雄激素性秃发既往称为脂溢性脱发或早秃，是一种发生于青春期和青春期后的毛发进行性减少性疾病，遗传易感毛囊在雄激素作用下出现具有特征性的脱发。

男性主要表现是前额发际线后退和（或）顶部毛发逐渐细少；女性主要表现为冠区头发弥漫性稀少，一般前额发际线保留。治疗上我们根据患者脱发严重程度和患者自身要求来制定治疗方案。

**斑秃**是一种突然发生的局限性脱发，局部头皮正常，无自觉症状，占皮肤科门诊患者的0.7%-3.8%。斑秃是一种自身免疫性、慢性炎症性疾病。因为免疫炎症的存在，让处于生长期的毛囊提早进入休止期。
严重类型包括**全秃、普秃、复发性、多发性斑片型及弥漫型**。**拉发试验**：阳性(活动期)。5天不洗头，拉起一小撮头发（50-60根），掉6根以上。

**拔毛癖**由于患者反复牵拉、扭转和摩擦毛发引起的脱发，也可因使用镊子、剪刀或剃刀所致。类似于神经官能症性表皮剥脱，这是一种自身导致的精神性疾病；就像有的人喜欢咬指甲一样。这个需要精神疏导。
**休止期脱发**由于毛囊病变导致的休止期毛发脱落，较多休止期头发同步性脱落，造成脱发的症状。急性休止期脱发的常见原因是发热、外伤、产后、大出血、减肥、心理压力；慢性弥漫性休止期脱发：甲状腺疾病、严重的缺铁性贫血、糖尿病、肠病性肢端皮炎、营养不良、药物等。
产后脱发，就是一种休止期脱发。因为产后体内激素水平发生剧烈变化，雌激素水平迅速下降，生长期头发比例降低，休止期头发比例增加，所以**很多产妇在产后4-6月发生脱发**。这个不要紧张，一般一年内恢复。**牵拉性脱发**由于拉扯头发或者高张力发型造成的,这种脱发消除牵拉因素就可以缓解。

**紫外线是什么？**
//

紫外线根据生物学效应和波长，主要分为短波紫外线（UVC，200-280nm）、中波紫外线（UVB，280-320nm）和长波紫外线（UVA，320-400nm）。紫外线辐射到皮肤表面后约有5%被弥散性反射，其余95%被透射、散射和吸收。强烈的长时间紫外线照射会引起皮肤晒伤、晒黑、皮肤光老化、皮肤光敏反应甚至发生皮肤癌等。

夏季是紫外线最强烈的季节。**每天10点至16点**是紫外线最强的时段，这个时间段应尽量避免外出。其实呢最好的防晒方法就是避光。出门要记得撑伞、戴遮阳帽、墨镜、口罩、穿防晒服等。其次，涂防晒产品，包括防晒霜、防晒乳、防晒喷雾等。
**//**

**我们如何选择防晒霜呢？**
//
现在市面的正规防晒产品外包装一定会标明生产企业的生产许可证、卫生许可证号、产品标准号等；也会标两个参数：SPF（Sun Protection Factor）和PA（Protection Factor of UVA）。SPF是日光防护系数，代表防晒类化妆品对UVB 的防护效果，SPF值越大，产品防日晒红斑的效果越好。
PA值反映防晒类化妆品对UVA 的防护效果，用“PA+”标识，“+”越多表示产品的防晒能力越强，一般夏季推荐使用防晒指数SPF50+( SPF≥50)，PA+++以上的产品。

比如，到海边需要选择SPF50+的防晒霜；去高原，比如西藏，需要选择SPF80+以上的防晒霜。即使在室内也要注意，因为玻璃只能阻挡UVB，无论是云层还是玻璃都无法阻挡UVA，**不管阴天还是晴天，我们都要做好防晒。阴天要做好UVA的防晒，UVA会导致光老化；晴天要防UVA和UVB，UVB会导致晒伤晒黑。**
**//**

**电动车和小汽车出行如何防晒？**
//

新交通法规要求电动车出行戴头盔，其实市面的头盔只能对头发的防晒起到作用（除了皮肤，头发也要注意防晒），暴露在外面的面颈部、项部、手臂，包括双手都需要做好防晒措施。**我们可以穿那种带帽子，遮脸的防晒上衣，然后戴手套，这应该才是电动车出行的防晒模式。**开车出行的亲们，千万不要以为在车里就万事大吉了，不需要防晒了。车窗玻璃不能阻挡UVA，所以帽子、防晒衣、手套、防晒口罩，也是出行必须装备。

**//**

**洗澡时如何注意护肤呢？**
//

夏天我们洗澡的目的就是清洁皮肤，去除汗渍，其实大部分时候，**清水冲洗**，几分钟就可以搞定，没有必要每次都使用肥皂、沐浴液，更不需要用硫磺皂，更不需要搓澡（长期搓澡的人很容易得摩擦性黑变病，皮肤变黑了）。

人的皮肤表面有一层皮脂膜，也是皮肤屏障的组成部分，每天用碱性产品清洗皮肤，很容易把这层具有保护作用的皮脂膜去掉，皮肤会变得干燥而敏感，很容易继发皮炎湿疹类皮肤病。还有一点，皮肤比较干的亲们，比如像我一样，即便是夏天，每次洗好澡，都会**涂上保湿产品**，给皮肤足够的保护。
