# 妇幼动态｜厦门市妇幼保健院举办世界母乳喂养周系列活动

> 更新时间：2026-09-16 (UTC+8)

点击“厦门市妇幼保健院”可以订阅哦！

母乳是天然的和最理想的哺育后代的食品，是妈妈给宝宝最好的礼物,不仅仅是宝宝最营养的食品，还是宝宝的第一剂疫苗。当宝宝生病时，母乳也可以当药物使用，起到缩短平均住院日的作用，没有任何一种产品像母乳那样经得起时间的考验。为促进社会和公众对母乳喂养重要性的正确认识和支持母乳喂养，世界母乳喂养行动联盟(WABA)将每年8月1日至7日为“世界母乳喂养周”。

为倡议和响应世界母乳喂养周的精神，厦门市妇幼保健院围绕今年的活动主题“母乳喂养，生命之源”，开展了系列活动，为准妈妈准爸爸们带来了一场母乳喂养知识的盛宴。

**01**

**公益互动活动——寓教于乐**

举办《母乳喂养大比拼》活动和《母乳喂养赞赞赞》互动训练营，通过设置形式多样的互动环节，让准爸爸准妈妈们在游戏中收获母乳喂养的知识和技巧。活动过程穿插母乳喂养知识有奖竞答，活跃现场气氛，提高学习热情。同时进行微信朋友圈我为母乳喂养代言集赞有奖活动，借助互联网让更多的人知道世界母乳喂养周，了解母乳喂养，支持母乳喂养。

▲现场哺乳姿势比赛

▲活动现场盛况

▲工作人员和获奖选手合影

▲我为母乳喂养代言微信朋友圈集赞

▲我在厦门市妇幼保健院，我为母乳喂养代言

**02**

**母乳喂养健康咨询——答疑解惑**

怀胎十月，一朝分娩。当真正开始哺乳时，很多人才发现当初在网上爬的文，看的书，做的功课，别人分享的喂养经验在自己这里行不通了。为了解决准妈妈、新手妈妈们的困惑，我院护理部、母乳喂养咨询门诊和健康教育学校组织了《母乳喂养社区行》和《母乳喂养专家面对面》的健康咨询活动。由本院母乳喂养技术指导小组和资深母乳喂养咨询师为活动现场的准妈妈和新手妈妈们提供无偿的一对一健康咨询，耐心解答孕妈妈们提出的各种问题，现场气氛非常活跃！很多妈妈都表示深受鼓舞，对产后母乳喂养充满了信心。

▲社区健康咨询活动 

▲母乳喂养专家面对面

**03**

**母乳喂养指导师培训——激情高涨**

8月4日-8日，由中国妇幼保健院协会主办，厦门市妇幼保健院协办的母乳喂养指导师培训班在我院2号楼9楼会议室正式开班。本次学习班邀请了北京丰台妇幼副院长唐艳、我院乳腺外科郭巨江主任、护理部黄银英主任等专家为学员讲授母乳喂养新知识、乳房护理、孕产妇心理指导等内容。学员们学习的热情高涨，课后积极在微信群上分享学习心得，每节课结束都还围着讲课老师积极提问，讲课老师也都表示被学员的学习热情所感动。

▲郭巨江主任回答学员问题

▲郭玉萍督导现场教学

**04**

**母乳喂养专题讲座——授人以渔**

为加大母乳喂养的宣传，提高母婴健康水平，产科四区何红玉护士长和产科门诊林艺红护士长以《母乳喂养方法与技巧》和《母乳喂养互动课堂》通过PPT展示讲解了母乳喂养的重要性，内容包括母乳喂养的好处、方法、技巧和喂养中的常见问题和误区，并现场通过教具教授正确的哺乳姿势、背部按摩操、新生儿抚触等。希望以简易生动的方式让准妈妈们习得母乳喂养的正确知识和技能，顺利完成母乳喂养。图文并茂的授课形式和浅显易懂的授课内容，深深地吸引了在场的每一位听众，受到准妈妈和准爸爸们的欢迎。

**05**

**新进员工岗前培训——全员掌握**

根据爱婴医院要求，也为了巩固爱婴医院成果，提高母乳喂养率，推动爱婴医院进一步建设和发展，加大母乳喂养知识的宣传力度，组织2018年新近员工进行爱婴医院知识的培训。课上，新员工拿着布娃娃、假乳房非常认真学习和演练，相信她们在今后的临床工作中可以更好的为产妇提供母乳喂养指导。通过培训，也有助于提高了我院职工对母乳喂养相关知识的知晓率，掌握母乳喂养专业技巧，使爱婴医院工作扎扎实实开展下去。

▲岗前培训

**06**

**产科病区特色活动——锦上添花**

除了全院范围内的“世界母乳喂养周”系列活动，我院产科病区借此契机，在病区内开展宣传庆祝活动。产科三区利用“317护”平台推送活动邀请函和母乳喂养知识，为在院的患者发放母乳喂养宣教单和宣教手册，同时在病区观景台举办母乳喂养现学现“卖”比赛；产科四区举办了一场“解读2018年成功母乳喂养10条”的知识讲座，和一场别开生面的“手工哺乳用具制作”活动；产科五区组织奶爸们进行喂奶姿势的体验和比赛以及母乳喂养知识竞答。病区的母乳喂养周宣传活动得到了产妇和家属们的一致认可，纷纷表示受益匪浅，对母乳喂养有更深入的认识，也坚定了妈妈们母乳喂养的信心。

▲产科三区母乳喂养技巧现学现“卖”

▲产科四区母乳喂养讲座和手工制作活动

▲产科五区奶爸喂奶姿势体验

我院作为“全国百家优秀爱婴医院”、“国家级母婴友好示范医院”，积极提倡母乳喂养。通过此次宣传周活动，广泛宣传了母乳喂养核心知识，使广大市民了解到母乳喂养的优点，深刻认识到母乳喂养的重要性，为落实〈促进成功母乳喂养十项措施〉的实施起到了有力的推动作用，未来的日子里也将持续致力于母乳喂养的宣教和指导。
