# 北京哪几家医院可以做试管三代？

> 更新时间：2026-09-11 (UTC+8)

北京有三家医院可以做试管三代，他们分别是北京大学第三医院、解放军总医院第六医学中心、解放军总医院第一医学中心。以上这三家医院都是具备开展第三代试管婴儿资质的医院，并且试管成功率都挺高的，平均成功率在30%-50%左右。建议患者可以根据自己的实际情况选择适合自己的医院，比如到医院的距离、医院坏境、医院收费标准等等。总体来讲，这三家医院的试管婴儿技术都是差不多的。
第三代试管婴儿的技术也称胚胎植入前遗传学诊断/筛查（PGD/PGS），指在IVF-ET的胚胎移植前，取胚胎的遗传物质进行分析，诊断是否有异常，筛选健康胚胎移植，防止遗传病传递的方法。第三代试管婴儿技术可以进行性别选择，但只有当子代性染色体有可能发生异常并带来严重后果时，才允许进行性别选择。本质上，第三代试管婴儿技术选择的是疾病，而不是性别。
第三代试管婴儿技术是我国目前最顶尖的试管技术，北京市目前也只有3家医院可以做第三代试管婴儿，他们的大致情况如下：北京大学第三医院：

- 1. 北京大学第三医院建于1958年，是一家集医疗、教学、科研、预防、康复与保健为一体的综合性三甲医院；
- 2. 解放军总医院第六医学中心：解放军总医院第六医学中心组建于2018年11月，是集卫勤、医疗、教学、科研、保健于一体的医学中心；
- 3. 解放军总医院第一医学中心：解放军总医院第一医学中心位于北京市海淀区南部，是集医疗、保健、教学、科研、预防、康复、核生化防护、医学救援于一体的大型现代化综合性医院。
